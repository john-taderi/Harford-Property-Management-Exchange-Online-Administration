# Room Mailbox
## Overview
This Room Mailbox is a resource mailbox in Microsoft 365 and Exchange Online that represents a physical meeting space, such as a boardroom, conference room, training room, or meeting hall for Harford Property Management(boardroomharfordpm@christtech.co.uk). It enables users to schedule and reserve meeting spaces directly through Outlook and Microsoft Teams.

# Business Benefits
- Streamlines meeting room reservations.
- Improves resource utilization.
- Reduces scheduling conflicts.
- Provides visibility into room availability.

# Equipment Mailbox
## Overview
An Equipment Mailbox is a resource mailbox that represents a shared piece of equipment that Harford Propertt Management(projectorharfordpm@christtech.co.uk) users can reserve for a specific period. 

# Conclusion
This setup improves scheduling efficiency, reduces conflicts, and provides a seamless booking experience for users across Outlook and Microsoft Teams.
