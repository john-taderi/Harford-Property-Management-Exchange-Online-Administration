# Distribution-group-deployment-exchange-online
## Overview
This project documents the creation and configuration of Distribution Groups for Harford Property Management using the Microsoft 365 Exchange Admin Center (GUI method).
The implementation was completed within Exchange Online to improve departmental communication, simplify email distribution, and enhance collaboration across teams.

# 🎯 Objectives
The goals of this distribution group implementation were to:
- Create centralized email distribution groups
- Improve internal communication efficiency
- Enable group-based email delivery
- Gain practical experience using Microsoft 365 Exchange Admin Center
- Understand group ownership and membership management

# 📌 Deployment Method
The Distribution Groups were created using the graphical user interface (GUI) within Exchange Admin Center.

# 🧭 Navigation Path - How I achieved this
Microsoft 365 Admin Center
    → Exchange Admin Center
        → Recipients
            → Groups
                → Distribution
                    → Add a Group
                    
# ⚙️ Deployment Procedure
Step 1 — Access Exchange Admin Center
Logged into Microsoft 365 Admin Center
Opened Exchange Admin Center

Step 2 — Navigate to Distribution Groups
Followed the navigation path:
Recipients
   → Groups
      → Distribution
         → Add a Group
         
Step 3 — Configure Distribution Group
During the setup process, the following configurations were completed:
- I entered Group Name
- Configured Email Address
- Added Group Alias
- Selected Group Owner
- Added Group Members
- Reviewed configuration settings
- Created the Distribution Group
