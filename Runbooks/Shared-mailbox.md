# 📧 Shared Mailbox Deployment – Harford Property Management

## Project Overview

This project documents the creation of shared mailboxes for Harford Property Management using the Microsoft 365 Exchange Admin Center (GUI method).

The implementation was carried out within Exchange Online to support centralized communication, collaboration, and departmental email management.

---

# 🎯 Objectives

The objectives of this task were to:

- Create departmental shared mailboxes
- Enable collaborative email access
- Improve communication workflow
- Centralize support and business communication
- Gain hands-on experience with Microsoft 365 Exchange Administration

---

# 🛠️ Technologies Used

| Technology | Purpose |
|------------|---------|
| Microsoft 365 | Cloud productivity platform |
| Exchange Online | Email and mailbox management |
| Exchange Admin Center (EAC) | GUI administration portal |
