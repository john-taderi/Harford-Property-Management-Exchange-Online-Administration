## Anti-Spam & Anti-Phishing Configuration
Implemented via Microsoft Defender for Office 365

## Spam Filtering Levels
Level	                                                               Action
Low confidence spam	                                            Move to Junk folder
High confide                                                    Quarantine
Phishing attempt	                                              Block and alert admin
## Anti-Phishing Policies
- Impersonation protection for executives (CEO, CFO)
- Domain spoof detection enabled
- Safe Links enabled for URLs
- Safe Attachments enabled for files

## Quarantine Policy
- Users notified daily of quarantined emails
- IT admin review required for release of high-risk messages
