## MailFlow Rules
Internal Mail Flow Policy
- Internal emails remain within organization unless explicitly forwarded
- Auto-forwarding to external domains disabled by default

External Email Control
Rule                                             Description
Block auto-forward                          Prevents data leakage
External warning banner                     Tags external emails
Domain whitelist                            Allows trusted partners only


Data Protection Rules
- Block emails containing sensitive data (BVN, credit card numbers)
- Apply encryption for financial documents
- Restrict attachment types (.exe, .bat, .js)
