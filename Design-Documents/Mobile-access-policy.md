## Supported Devices
iOS (iPhone/iPad)
Android devices
Windows Outlook mobile app

## Security Requirements
Device must be enrolled in Mobile Device Management (MDM)
PIN/biometric authentication required
Device encryption mandatory
Jailbroken/rooted devices blocked

## Access Control
Conditional Access policy enforced via Microsoft Entra ID
Require MFA for all mobile logins
Block legacy authentication (POP/IMAP/SMTP basic auth)

## Data Protection on Mobile
Company data separated from personal apps (app protection policies)
Copy/paste restrictions for sensitive emails
Remote wipe enabled for lost devices

## Monitoring & Logging
Mailbox audit logs enabled
Admin activity logging active
Security alerts integrated with Microsoft 365 Defender
Weekly review of quarantine and blocked messages

## Compliance & Governance
Data retention policy: 7 years for financial emails
Legal hold enabled for Info and finance mailboxes
GDPR-style data protection principles applied
